Vi Sao The Nhi Uploader

Vi Sao The Nhi Uploader là công cụ cá nhân của kênh YouTube Vì Sao Thế Nhỉ. Công cụ chạy trên máy tính của chủ kênh và dùng YouTube Data API để tải video do chính kênh sản xuất lên kênh này, đặt tiêu đề, mô tả, ảnh bìa và lịch công khai.

Vi Sao The Nhi Uploader is a personal tool for the YouTube channel "Vì Sao Thế Nhỉ". It runs on the channel owner's computer and uses the YouTube Data API to upload the channel's own videos to that channel and set their title, description, thumbnail and publish schedule. It is not offered to the public.
